# Aura Maison — Women's Hair & Beauty Studio

Vue 3 + Vite, plain CSS. Bookings go to WhatsApp.

```
npm install
npm run dev      # local preview
npm run build    # outputs to dist/
```

Deploy to Cloudflare Pages: build command `npm run build`, build output directory `dist`.
If the files sit inside a folder in your repo, set that folder as the Root directory (not the output directory).

Edit `src/data.js` to change the WhatsApp number, services and prices.
